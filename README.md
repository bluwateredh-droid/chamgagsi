# 개굴개굴 서바이버

귀여운 개구리가 연못에서 벌레 떼를 물리치는 설치 없는 브라우저 게임입니다.

## 실행

Windows에서는 `게임실행.cmd`를 더블클릭하세요. 또는 `index.html`을 Chrome, Edge, Safari, Firefox 등 최신 브라우저에서 열면 바로 실행됩니다.

## 아이폰·갤럭시

모바일 브라우저에서 배포된 게임 주소를 열면 바로 플레이할 수 있습니다.

- 아이폰: Safari의 공유 버튼 → `홈 화면에 추가`
- 갤럭시: Chrome 메뉴 → `홈 화면에 추가` 또는 `앱 설치`

홈 화면에 추가한 뒤에는 전체 화면과 오프라인 플레이를 지원합니다. PWA 설치 기능은 HTTPS 웹 주소에서 작동하므로, ZIP을 웹 호스팅(GitHub Pages, Netlify 등)에 한 번 업로드해야 합니다.

## 조작

- PC: WASD 또는 방향키
- 모바일/태블릿: 게임 화면을 누른 채 드래그
- 공격: 가장 가까운 적을 향해 자동 발사

경험치 보석을 모아 레벨업하고, 세 가지 능력 중 하나를 골라 오래 생존하세요.

## 캐릭터와 특수 구역

- 참각시 개구리: 균형 잡힌 기본 캐릭터
- 참서방 오소리: 조금 느리지만 체력, 공격력, 방어력이 높음
- 동부센트레빌: 매 1분마다 50% 확률로 맵에 10초간 등장하는 무적 구역. 구역 안에서도 공격과 적의 추격은 계속됩니다.
