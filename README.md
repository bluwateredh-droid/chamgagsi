# 개굴개굴 서바이버

귀여운 개구리가 연못에서 벌레 떼를 물리치는 설치 없는 브라우저 게임입니다.

## 실행

Windows에서는 `게임실행.cmd`를 더블클릭하세요. 또는 `index.html`을 Chrome, Edge, Safari, Firefox 등 최신 브라우저에서 열면 바로 실행됩니다.

## 아이폰·갤럭시

모바일 브라우저에서 배포된 게임 주소를 열면 바로 플레이할 수 있습니다.

- 아이폰: Safari의 공유 버튼 → `홈 화면에 추가`
- 갤럭시: Chrome 메뉴 → `홈 화면에 추가` 또는 `앱 설치`

홈 화면에 추가한 뒤에는 전체 화면과 오프라인 플레이를 지원합니다. PWA 설치 기능은 HTTPS 웹 주소에서 작동하므로, ZIP을 웹 호스팅(GitHub Pages, Netlify 등)에 한 번 업로드해야 합니다.

## 조작

- PC: WASD 또는 방향키
- 모바일/태블릿: 게임 화면을 누른 채 드래그
- 공격: 가장 가까운 적을 향해 자동 발사

모바일 플레이 중에는 게임 캔버스 자체가 `visualViewport`의 실제 비율로 변경되어 화면 전체를 사용합니다. 체력·시간·보스·경험치 UI는 화면 폭에 따라 다시 배치되며, 터치한 위치에는 드래그 방식의 가상 조이스틱이 나타납니다. 카카오톡 인앱 브라우저, Safari, Chrome의 주소창 변화와 화면 회전도 실시간 반영합니다.

게임 시작 시 지원되는 브라우저에는 전체화면을 요청합니다. 배경은 노치 영역까지 확장되고 체력·보스·경험치 UI는 노치와 홈 인디케이터를 피한 안전 영역 안에 표시됩니다. 홈 화면에 설치한 PWA는 `fullscreen` 모드로 실행됩니다.

맵에는 경계나 벽이 없으며 어느 방향으로든 계속 이동할 수 있습니다. 카메라는 캐릭터를 따라가며, 특수 구역은 생성 시 현재 플레이어가 보고 있는 화면 안에 배치됩니다.

경험치 보석을 모아 레벨업하고, 세 가지 능력 중 하나를 골라 오래 생존하세요.

## 캐릭터와 특수 구역

- 참각시 개구리: 균형 잡힌 기본 캐릭터
- 참각시 개구리 월드: 하늘색 연못 배경과 연꽃 적
- 참서방 오소리: 조금 느리지만 체력, 공격력, 방어력이 높음
- 참서방 오소리 월드: 연녹색 숲 배경과 꿀벌 적
- 동부센트레빌: 매 1분마다 50% 확률로 맵에 10초간 등장하는 무적 구역. 진입하면 구역마다 정화 충격파가 한 번 발동해 주변 일반 적을 즉시 처치하고 강화 적과 보스의 최대 체력 30%를 감소시킵니다. 구역 안에서도 공격과 적의 추격은 계속됩니다.

캐릭터 선택 화면에는 각 캐릭터의 이야기와 게임 목표가 표시됩니다. 최종 보스 CM을 처치하면 생존 성공 메시지와 `종아리 마사지 쿠폰` 보상이 나타납니다.

## 보스와 승리 조건

3분마다 새로운 보스가 등장하며, 30분에 등장하는 10단계 최종 보스 `CM`을 처치하면 게임을 클리어합니다.

1. 아기 둘기
2. 어른 둘기
3. 윤석열
4. 탄핵 윤석열
5. 호중
6. 음주 호중
7. 갬돌이
8. 웹툰부장
9. 지구온난화
10. CM

보스는 일반 적보다 훨씬 크고 빠르며 화면 밖으로 달아나도 계속 추격합니다. 멀어지면 추격 속도가 상승하고 체력이 절반 이하가 되면 광폭화합니다. 화면 밖에 있는 동안에도 방향 화살표와 이름이 표시됩니다.

## 특수 아이템과 구역

- 모든 기본 공격은 스플래시 피해를 주며 공격력, 탄환 크기, 파동 증폭 강화에 따라 직접 피해와 폭발 피해가 함께 성장합니다.
- 파워 씨앗: 공격력 6%, 폭발 반경 5, 주변 피해 배율을 영구적으로 강화합니다.
- 아쿠아 슈즈: 적이 낮은 확률로 떨어뜨리며, 획득하면 10초 동안 무적. 지속 중 기본 공격의 폭발 범위와 주변 피해도 50% 강화됩니다. 획득 순간 주변 일반 적은 즉시 처치하고 강한 적과 보스는 최대 체력의 3분의 1만큼 피해를 받습니다.
- 할램: 매 1분마다 20% 확률로 3초간 등장. 구역 안에서는 이동속도가 25% 감소

## 레벨업 테크트리

- 공격: 파워 코어, 연속 공격, 다중 발사, 급소 감각
- 범위: 거대 탄환, 파동 증폭
- 생존: 생명력, 수호막, 재생력, 민첩한 발
- 성장: 경험치 자석
- 진화: 선행 능력의 요구 단계를 만족하면 대홍수, 탄막 폭풍, 불굴의 심장이 선택지에 등장합니다.

배경음악은 저작권 음원을 복제하지 않은 게임 전용 오리지널 멜로디입니다.
